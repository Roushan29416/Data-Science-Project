
## Data-Driven Analysis and Prediction of Digital Well-being

### Project Overview
This is a Data Science project that analyses the relationship between social media usage, screen time, sleep quality, stress levels, and happiness.

The project uses data analysis and machine learning techniques to understand patterns in digital well-being and predict the Happiness Index.

### Problem Statement
Excessive screen time and social media usage may be associated with changes in sleep quality, stress levels, and overall happiness. 
This project explores these relationships using a data-driven approach.

### Objectives
- Analyse digital well-being patterns.
- Study relationships between screen time, sleep, stress, and happiness.
- Perform data preprocessing and exploratory data analysis.
- Build and compare machine learning regression models.
- Develop an interactive Streamlit dashboard.

### Dataset
**Dataset:** Mental Health and Social Media Balance Dataset

**Source:** https://www.kaggle.com/datasets/prince7489/mental-health-and-social-media-balance-dataset

**Size:** 500 rows and 10 columns.

**Target Variable:** Happiness Index (1–10).

### Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Streamlit
- Git and GitHub

### Machine Learning Models
- Linear Regression
- Random Forest Regression
- Gradient Boosting Regression
- Tuned Random Forest Regression

### Best Model
Tuned Random Forest Regression.

- MAE: 0.7195
- RMSE: 0.8948
- R² Score: 0.6630

### Interactive Dashboard
The project includes a Streamlit dashboard for data visualisation and interactive Happiness Index prediction.

### Project Structure
- data/ — Dataset
- dashboards/ — Streamlit application and trained model
- reports/ — Project documentation and experiment reports
- presentation/ — Presentation materials

### Limitations
The dataset is observational and self-reported. The results identify statistical relationships and do not establish causation. Predictions are for 
educational and analytical purposes, not clinical assessment.
